## 4. 원본 XBRL 통합 결과

실제 호출은 `fnlttXbrl.xml`, `rcept_no=20260814003521`, `reprt_code=11012`였습니다. ZIP 내 인스턴스 이름은 `entity00164742_2026-06-30.xbrl`였고, 정의·계산·표시·라벨 파일도 있었습니다. ZIP은 메모리에서 파싱했습니다. [OpenDART 재무제표 원본파일](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019019)

검증 기준값 (단위 원, 회사 `00164742`, 연결 전체, 통화 KRW, 원본 `decimals=-6`):

| 표준 개념 | 2026-01-01~06-30 | 2025-01-01~06-30 |
| --- | ---: | ---: |
| `ifrs-full:CashFlowsFromUsedInOperatingActivities` | 4,849,653,000,000 | 959,651,000,000 |
| `ifrs-full:ProfitLoss` | 5,472,888,000,000 | 6,632,564,000,000 |

두 기간 모두 `ifrs-full:ConsolidatedAndSeparateFinancialStatementsAxis`의 `ifrs-full:ConsolidatedMember`만 있는 연결 전체 문맥을 선택했습니다. 순이익은 같은 값이지만 `CarryingAmountAccumulatedDepreciationAmortisationAndImpairmentAndGrossCarryingAmountAxis`에 `dart:ReportedAmountMember`가 추가된 문맥에도 있었습니다. 값이 같아도 다른 문맥이므로 일반 연결 전체 후보와 섞지 않습니다. `decimals=-6`은 반올림 정밀도이며 원금액에 다시 백만을 곱하는 배율이 아닙니다. 기존 엔진에서 `Fact.unit`이 배율·대조 허용오차에 쓰이는 지점을 확인하고, 정밀도와 배율은 구분해 연결하세요.

구현·검증 완료 범위

1. **완료 · 독립 파서.** `dart_analyst/xbrl.py`의 `read_xbrl_archive(payload)`가 ZIP과 XBRL을 읽습니다. ZIP/XML 한도와 경로를 검사하고 DTD·엔티티·외부 참조를 차단합니다. 회사·기간·축·구성원·통화는 XML에서 읽으며 QName은 네임스페이스로 해석합니다. 실제 현대차 원본에서 수치 사실 4,745건을 읽었으며 위 표의 기준값 네 개를 확인했습니다. `tests/test_xbrl.py`는 네트워크 없이 파서 동작과 거부 조건을 검증합니다.
2. **완료 · 공통 계정 통합.** `DartClient._apply_xbrl()`가 모든 선택 기간의 지원 표준 개념을 `Period.facts`와 `comparatives`로 전달합니다. 이마트 2023년 최종 공시 `20240320001939`, 현대글로비스 2024년 최종 공시 `20250318000748`는 전체계정과 접수번호가 다르고 XBRL API에서 원본 파일 없음을 반환해 보류됩니다. 근거가 없는 원천 값으로 복구하지 않습니다.
3. **완료 · 출처와 충돌.** 접수번호는 `Fact.source_id`, API·보고서 코드·파일·QName·문맥·단위·정밀도·후보 금액은 `Fact.source_details`에 기록합니다. 적합한 수치가 없거나 금액이 충돌하면 보류를 기록합니다. 원본 수집이나 파싱이 실패하면 기존 전체계정 결과를 사용하며 검증 보류를 표시합니다.
4. **완료 · 회귀 검증.** 소형 ZIP fixture로 3개월과 누적 기간, 연결과 별도, 추가 축, 회사·식별자 스킴·통화, 동일값과 충돌, nil과 비정상 수치, ZIP/XML 보안을 확인했습니다. 현대차 실제 기준값을 확인했고 제주반도체·LG에너지솔루션에서 기존 매출과 흑자·적자 표시의 기반 수치, 두 계정 수집, 주석 5개 발췌를 재검증했습니다.
5. **완료 · 주석과 자료 확인사항.** 확인된 원문 문자 유형만 제한적으로 보정하고, 원문 주석 실패를 별도 표시합니다. 동일 기간에 같은 이유로 보류된 현금흐름 계정은 공시 번호와 함께 화면에서 묶습니다.
